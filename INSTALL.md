# Install MotoLine (Android)

This is a private test build — not from Play Store.

## Steps for friends

1. Open the **GitHub Release** link you were sent.
2. Download **`MotoLine-v0.1.0.apk`**.
3. On your phone: open the downloaded file.
4. If Android blocks it, allow **Install unknown apps** for your browser/Files app.
5. Install → open **MotoLine** → allow **Location** (needed to draw your ride line).

## Tips

- Use a real ride outdoors; GPS indoors is weak.
- Keep the phone mounted; don’t interact with the screen while riding.
- Android only for this APK. iOS needs TestFlight (later).
